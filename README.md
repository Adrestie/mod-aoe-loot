# mod-aoe-loot
AzerothCore mod for QoL

#L'idée
si plusieurs monstres sont lootable pour le joueur dans une zone de X mètres et que le joueur loot un de ces monstres, tous les montres sont looté en même temps.

Cela se traduit par : 
- une seule fenêtre de loot
- les objets non récupérés restent lootable sur les monstres qui les dropaient
- les objets de quêtes sont aussi récupéré sans dépasser les montants nécessaires
- les objets de quêtes ne sont pas dupliqués si plusieurs joueurs fouillent les cadavres
- le système de jet de butin fonctionne sans modification
- les objets éligibles aux jets de butins ne sont pas dupliqué si plusieurs joueurs fouillent les cadavres
- ne fonctionne que sur les cadavres de monstres
